Hola, buenos días, tardes o noches. Mi nombre es Alex Daniel Nobza y soy desarrollador web junior en proceso de formación. Actualmente estoy reforzando conceptos de HTML, CSS, Git, React y Figma, con el objetivo de convertirme en un desarrollador Full Stack capaz de crear soluciones web funcionales, estructuradas y orientadas a resolver problemas complejos.

Este proyecto es mi portafolio personal, pensado para presentar mi perfil profesional, mostrar las tecnologías que manejo, destacar proyectos realizados y dejar un medio de contacto claro para futuras oportunidades.

## Descripción del Proyecto

Este repositorio corresponde a un sitio web estático de portafolio personal desarrollado en HTML y CSS. Su propósito es mostrar quién soy, qué tecnologías estoy aprendiendo y aplicando, qué proyectos he desarrollado y cómo puedo ser contactado.

La estructura del sitio está enfocada en una experiencia visual moderna, con diseño oscuro, tipografías personalizadas y una presentación centrada en el mi perfil profesional.

### Tecnologías Utilizadas

- HTML5 para la estructura semántica del contenido.
- CSS3 para el diseño visual, layout responsivo y estilos del sitio.
- Fuentes locales personalizadas para mejorar la identidad visual.
- Imágenes y SVGs para la representación gráfica de habilidades y proyectos.
- GitHub Pages como enfoque de publicación para la versión final del portafolio.

## Instalación

Para ejecutar este proyecto de forma local, sigue estos pasos:

1. Clone el repositorio:

   ```bash
   git clone https://github.com/Archralex9609/web_project_portfolio_es.git
   ```

2. Acceda a la carpeta del proyecto:

   ```bash
   cd web_project_portfolio_es
   ```

3. Abra el archivo `index.html` en tu navegador preferido, o usa una extensión como Live Server en tu editor para visualizar el sitio en tiempo real.
